## 2. 关键发现与结论

1. **原回测收益常数 (586.81U) 的根因**:
   - 原有寻优与基线回测均采用固定名义金额（每笔 100U），不论账户权益增长到多大，仓位完全不随权益放大。
   - 实验 A 清晰重现了固定仓位的线性格局，终值受限于固定的单笔 100U 敞口。

2. **实验 B (每日比例复利) 的收益与风险动态**:
   - 在盈利阶段（Days 1-7），日切自动将新单额度由 100U 扩大至 150U+，有效提升资金利用率与对数增长率；
   - 在回撤阶段（Days 8-10），随着盯市权益缩水，新单名义额度同步缩减，自然保护账户资本；
   - 盘中实时检查保证金比例，超限单立即被拒，不产生幽灵成交。

3. **实验 C (风险自适应扩展) 的平滑与控撤效果**:
   - 采用非对称平滑基准 $B_d = \min(E_d, (1-\alpha)B_{d-1} + \alpha E_d)$，盈利时循序渐进放大，亏损时果断下调；
   - 触及 10% 回撤阈值时，自动将单笔额度折半（0.5x），显著降低了 UI 和 CDaR 尾部回撤；
   - 迟滞恢复机制避免了在反弹边缘频繁切换仓位状态。
