# 测试与交易行为回归

测试约束交易结果，不约束实现必须经过哪些类、调用几次私有方法或使用哪种缓存/复制方式。先验证替代覆盖，再删除旧测试；不整体清空真实故障的回归依据。

## 最新架构简化回归

基于 3c652c4d 的本地修改：删除重复命令锁模式，测试改为验证 Coordinator 的同键排序和 WS 事实独立推进；生命周期锁测试改用 hold 接口。恢复模型迁移后同步所有测试及复现脚本引用。新增“直接失效提供者也推进预取代次”的回归，避免账户事件绕过 Runtime 后旧预取仍被接受。

订单未知结果、排队取消、宽限退出、同批次预留和提交回滚的行为用例保留。源码模块扫描包含 TYPE_CHECKING，349 个模块未发现静态依赖环。

本轮进一步删除未接线遥测、只服务旧 REST 成交量缓存、重复检查点调度和无效 Readiness 更新的测试。成交量验证改为真实 Hub 输入下的因果历史、标的过滤、历史上限及资源释放；新增多批次预留持久化失败时数据库和内存均无部分发布的回归。架构测试同步合并后的协议路径，保留无存储依赖检查。

删除 RuntimePlan 专用的多哈希、来源链、密钥引用和假想默认模式测试；删除 Paper 报告挂载未持久化计划对象的测试。替代验证直接覆盖实盘 EffectivePolicy 的市价/限价选择、金额、仓位上限、非正金额拒绝及不虚构 20 分钟退出。新增缺少 commit/migration/lease 元数据仍可加载真实交易清单的验证；CLI 测试同步删除已退役的参数。流连接状态预算、启动恢复失败不得暴露发单协调器、运行资源清理测试继续保留。

后台恢复接口改为返回查询计划，测试不再注入收集回调。保留“恢复命令与未解决订单每轮只查询一次”、失败后继续轮转、查询预算和局部恢复调度用例；PostgreSQL 终态收据测试直接验证返回空查询计划及账本收敛。删除未使用的故障回调和局部变量。

旧纯加载函数测试替身补齐完整读者契约；生产不保留这种兼容。定时退出测试现在反映真实过程：发单前交易所持仓非零，退出后才归零。删除空仓必须等行情及等待接口可以缺失的旧用例，验证空仓不读取旧上下文。退出测试明确提供账户和两个利润阈值，仍覆盖首根逆向 K 线与宽限到期的不同判断。

新增 primary/account-3 两种仓位分类归属回归；重建测试明确传入账户与环境，旧缺字段替身补齐观察时间字段。已退役的缺字段身份/数量/时间推断不再是生产兼容入口；历史订单碰撞、部分成交、外部平仓和迟到成交用例仍保留。
