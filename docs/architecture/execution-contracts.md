# 执行与数据契约

核对日期：2026-10-05；当前实现与保留的业务底线。安装入口和部署状态见[仓库现状](../current-state.md)。

## 订单与事务

1. 每次提交有稳定 client_order_id；同身份同请求幂等，同身份不同载荷是冲突。网络超时不能改身份再 POST。
2. 准备事务保存订单、意图和相关预留后才调用交易所。网络请求在数据库事务之外；后续响应或成交吸收另有持久化提交，不宣称整笔订单只用一个事务。
3. 明确未发包或业务拒绝与“可能已到达交易所”分开。发包后超时、5xx 或无法解析响应按未知结果恢复；单订单反查保留，不盲目重发或释放占用。
4. ExchangeOrderRow 是交易所订单状态权威。命令状态保留本地发送/结算责任；终态但缺实际成交事实不能提前释放批次责任。
5. 排队请求取消且尚未执行时不 POST；已经发包的取消不能推断订单不存在。不同标的独立调度，退出和撤单优先。
6. 量化使用交易所步长与精度，批准金额和配置硬顶不能因量化向上突破；在途订单计入相关敞口。

## 成交、批次与退出

批次术语以 [CONTEXT.md](../../CONTEXT.md) 为准：同方向追加开仓在平仓提交边界之前属于同一批次；之后新成交进入新批次。数量、成本、身份和剩余预留来自真实成交，不用账户总量或时间接近度猜归属。

同一标的配置允许两笔开仓时，两笔共用一个退出批次；价格按实际成交数量加权，时间锚点由第二笔成交推进，第一笔的迟到部分成交不改写第二笔时间。准入按不同开仓订单身份计数，包含待成交订单；部分成交订单与其挂单只计一次，结果未知的订单继续阻断加仓。退出优先：提交平仓即封批，不再向该批追加；封批不等于持仓归零。封批后的新开仓属于新批，旧批不占用新批的开仓名额；冷却、未知订单和总敞口限制仍生效。策略计时和新的退出分配只针对尚未封批的批次，旧批退出由已持久化的订单/预留继续负责。

恢复检查点格式 4 保存批次内全部开仓订单身份；旧格式缺失这些证据，不能推断为一笔或直接改写版本号。上线需停妥旧消费者，以完整原始成交事实重建并核对仓位、成本、数量、批次锚点和订单计数；证据不完整时保持禁止新开仓。不启用旧格式兼容读取，部署脚本拒绝该格式升级的滚动实盘更新。

重复成交不重复计量；累计成交水位不回退；旧 ACK 不能覆盖已确认终态。数据库提交失败不发布新内存事实版本，重启仍能恢复原状态。

正式 15m 收盘事件独立驱动退出。跳过最新开仓所在的 K 线；已提交的宽限限价单关联原批次和首次截止时间，不因重试重新开始宽限。到期撤单并对剩余数量请求 reduce-only 市价退出，无需等下一条行情。

当前默认配置为 8 根、直接退出阈值 0.001、宽限目标 0.0088。截止时间按持久化 `recovery_exit_started_at + 15m × bars` 计算；是否与预期收盘边界完全一致要检查实际边界来源，不能把“8 根”写成额外等到每日定时平仓。交易参考价与阈值以实际代码和配置为准，见[实盘手册](../runbooks/small-capital-live-session.md)。

对账告警、旧租约和监控状态不阻断正常退出。reduce-only 仍需有效方向、真实可用数量和可追踪订单身份；若同一退出已经发包但结果未知，先恢复该订单，不能重复平掉同一预留。

## 事实恢复与资源

- 等待覆盖证据不等于同身份不同载荷的真实矛盾；按仓位隔离恢复责任，不能把缺历史证据改成虚构空仓。
- 后台恢复有独立任务预算和轮转，普通账户事实不反复触发整本历史扫描。慢恢复不能持有其他标的发单通道。
- 创建资源的装配者负责释放；装配失败、正常关闭和取消均释放已创建的池/客户端。监控、看板和遥测失败不改变订单执行结果。
- PostgreSQL 是恢复与审计边界；看板查询有时间/行数范围。保留期保护活动批次、未知订单、未完成结算及恢复消费者水位，不能只按日期删除真实成交。

## 当前格式与退役边界

当前凭证必须按 read/trade 角色配置，无通用密钥回退。命令/预留仓库使用异步接口，无同步自动适配和签名探测；入场策略不保留 compare-only 分支。实盘收盘退出不回退到普通行情触发的 REST K 线加载。

恢复检查点使用 schema 4，账户事实使用 schema 3，Collector 日志及检查点使用 schema 2。策略恢复读取当前持久化状态头；已有决策日志但缺状态头不自动导入旧日志。Capture 的 realtime/durable 延迟字段、Universe 的 loser_target_count 和 CML_LIVE_POSITION_ACCOUNT_LABELS 使用当前配置契约。

旧配置、日志不自动升级；历史数据库迁移与保留模型不是当前运行功能。无引用的 ExecutionRunMode/ExecutionReadiness 和影子运行入口已删除。验证位置集中于[测试说明](../testing/behavior-tests.md)。
