# 当前运行契约：删除历史兼容路径

本次清理停止接受旧接口、旧配置和旧持久化格式，调用方及测试统一使用当前契约。

- Binance 凭据必须按 read/trade 角色分别配置；删除通用凭据回退及 `allow_shared` 迁移开关。
- 执行账本直接等待异步命令和预留仓库；删除同步仓库自动适配器及客户端方法签名探测。
- 入场策略固定执行当前资格策略；删除 compare-only 模式、双轨比较结果和相关 CLI 开关。
- 仓位账本只使用真实成交；删除订单数量推导的合成成交、复用订单 ID 的历史拆分和自动修复。
- 实盘 K 线退出只由独立的已收盘 15m K 线事件触发；删除旧行情状态触发的 REST K 线加载路径。
- 恢复检查点只接受 schema 3；账户事实序列化更新为 schema 3，删除旧数量检查点模型及编解码。
- 策略启动只读取当前持久化状态头。已有决策日志但缺少状态头时明确拒绝启动，不再导入旧日志。
- 成交重放只接受当前业务事实摘要，并校验持久化来源事实完整性；删除旧摘要放行逻辑。
- Collector 日志及检查点只接受 schema 2；要求明确的 record_id、accepted_sequence 和 materialized_sequence，删除旧 spool 恢复和游标推断。
- Capture 只接受 realtime/durable 两个关闭延迟字段；Universe 必须明确配置 loser_target_count；实盘账户订阅使用 CML_LIVE_POSITION_ACCOUNT_LABELS。
- 删除 paper run 历史字段升级和旧配置哈希别名；现金流指标认证要求当前覆盖证明。

历史配置、日志或运行记录不会自动迁移。现有数据库迁移脚本及当前恢复、完整性、风控检查仍保留。
