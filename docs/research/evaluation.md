# 本地研究与实盘对照口径

核对日期：2026-10-04。本文合并研究设计的有效数据、权益与前向评价约束。当前工具入口见[研究手册](../runbooks/local-full-data-optimization.md)；本地源码被 Git 忽略，本文不宣称设计全部实现或历史结果全部合格。

## 范围与数据

当前研究主线为 Orderflow 短周期动量：收益脉冲、主动买卖不平衡、相对成交强度与可选成交额过滤。Compression/Liquidation 已退出当前运行包；历史课题不作为新增系统入口。

每次实验固定数据快照、UTC 窗口、可用时间、完整配置、成本、搜索空间和预算。参数改变检测逻辑时必须从原始行情重新检测，或证明机会池覆盖所有候选参数；当前账户已成交集合不能替代原始机会池。缺桶、排名代理、价格缺口与未结束交易单独标记。

本地已有 opportunity、simulation_ledger、MTM、walk-forward 与 reconciliation 实现；不能继续将 9 月设计中的缺陷无核对地写成当前故障。每次结果实际覆盖情况需由输入、产物和测试确认。

## 权益与风险指标

无外部现金流时：`E(t) = E0 + 已实现毛收益 - 手续费 + 资金费净收入 + 未实现收益`。杠杆影响保证金，不能把按名义仓位算出的 PnL 再乘杠杆。实盘同时保留真实账户权益与剔除外部现金流后的策略归因。

跨窗口持仓、挂单、冷却与批次不得清零；区间收益按 E(end)-E(start)，期末未平仓盯市，不丢弃浮亏。统一时间网格上计算高水位 H(t)、回撤 D=H-E 与 d=D/H，记录分辨率；粗网格可能漏掉桶内极值。

|指标|定义/用途|
|---|---|
|MDD|max d，最坏历史下跌|
|Ulcer Index|sqrt(时间权重下 d² 均值)，关注深度和持续时间|
|CDaR 95%|d 的时间加权分布最差 5% 尾部均值|
|水下时长|最长未恢复时间与比例；未恢复事件保留|
|日内回撤|每日局部高水位回撤；同时保留跨日回撤|
|收益集中度|币种、日期与最大盈利贡献，标注样本数|

自然峰值保证金约束是整组参数可行性筛选；运行时资金不足拒单会改变路径，两者不能混用。280/350 USDT 等旧数值只是历史研究条件，不是未来安全保证。研究固定仓位与复利另列协议。

## 选参和前向评价

- 全量历史选优回答历史发现；冻结参数后才到达的数据回答前向表现。daily_best 不自动成为 recommended。
- 所有场景用相同数据/成本/时间窗口，只改变声明的约束。先满足硬约束与覆盖，再在近优候选中比较收益、回撤和邻域稳健性；分数和阈值提前固定。
- Walk-forward 使用连续 state_in/state_out，按窗口边界 MTM 权益差归因。训练只能用当时可见结果；旧持仓和期末未平仓不能从所有窗口删除。
- 同时保留旧参数在旧窗口、旧参数在共同新窗口、新参数在共同窗口和冻结新增区间结果。数据修订与引擎修复另列 restatement。
- 最优只在已完成的搜索空间内成立；零交易、缺数据、任务失败与无可行参数分开。小样本和同市场相关交易不假装独立统计证据。

## 实盘对照

三种证据分开：决策复现用当时可见输入；真实成交账本重建验证记账；独立模拟检验成交假设。不得注入真实信号后宣称策略复现，也不能把模拟到期等同于真实撤单。

按配置生效区间恢复期初批次、挂单和现金流，遵守[批次术语](../../CONTEXT.md)。订单类型/TTL、交易精度、费用、杠杆、定时窗口、宽限与执行延迟都影响可比性；策略哈希不一定覆盖完整执行配置。输出缺失机会、被过滤、拒单、未成交、成交价格和退出时差，不仅比较总 PnL。

本地性能优化参考[计算实践](performance.md)，但回放通过不证明实盘未知订单、部分成交、批次预留或网络取消正确；这些由[交易回归](../testing/behavior-tests.md)验证。
