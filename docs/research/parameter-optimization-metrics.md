# 本地参数寻优：回撤指标与验证方法研究

研究日期：2026-09-18。本文是设计依据，不是实现方案或实盘收益承诺。标准指标定义附一手来源；日内聚合、选择规则与数据契约为针对本项目提出的设计建议。

具体项目默认选择规则以[主设计文档](../superpowers/specs/2026-09-18-local-parameter-optimization-design.md)为准；本文保留其他可选研究方法，不表示同时启用。固定名义仓位下，主设计以净收益及日均净收益/E0为主要收益口径；下文对数增长是正权益条件下的补充观察量，不隐含复利仓位。

## 1. 结论

推荐把目标拆成“收益能力、回撤深度及持续时间、极端风险、稳定性”，采用**先硬约束，再展示收益—风险 Pareto 前沿，再按事先固定的规则选出推荐参数**。最大回撤继续作为风险上限；主回撤度量用全路径 Ulcer Index（UI），辅以 CDaR、最长水下时间及日内最大回撤分布。不要直接把这些高度相关的指标全部加权相加。

每日追加数据会改变问题本身，因此“参数连续不变”只能称为操作稳定，不能证明统计收敛或未来收益。应同时观察样本外表现、参数邻域是否形成平台、旧参数相对新参数的损失，以及不同市场窗口的一致性。

## 2. 统一权益路径，否则指标不可比

本项目建议用含未实现盈亏、手续费、资金费及滑点的组合权益 `E(t)`，不能只用已平仓累计盈利。比较时固定初始资金、仓位规则、杠杆、可交易集合、数据区间、估值价格和采样频率；外部出入金必须剥离。无交易但数据正常的时间仍计入风险与收益；数据缺失不能视为零风险。

设 `H(t)=max(E(s), s≤t)`，`d(t)=1-E(t)/H(t)` 为非负百分比回撤。以等间隔时间点统计；不规则事件流先重采样或按持续时间加权，不能让交易密集时段获得额外权重。权益必须为正；发生破产或强平的路径标记为不可行，不能靠裁剪分母继续得到“优良”指标。

另保留 USDT 绝对回撤供资金预算使用；它不能替代百分比风险。固定仓位研究与复投账户要分别标注。用峰值保证金作为收益分母容易把使用资金少的候选夸大，应同时报告固定账户资金收益、净利润和峰值/平均保证金。

## 3. 候选指标及边界

| 指标 | 本项目定义或约定 | 适用角色 | 主要不足 |
|---|---|---|---|
| 最大回撤 MDD | `max d(t)` | 极端损失硬上限 | 只看最坏一个点，不区分恢复速度 |
| Ulcer Index | `sqrt(mean(d(t)^2))` | 主回撤风险轴 | 样本长短、估值频率、窗口起点影响结果 |
| CDaRα | 回撤观测分布最差 `1−α` 尾部的均值 | 严重水下状态约束/辅助轴 | 长回撤贡献许多相关观测，不能当独立尾部事件数 |
| 最长水下时间 | 从高水位起到恢复原高位的最长历时 | 防止长期套住 | 浅回撤也可能持续很久，须联看深度 |
| 水下占比 | `mean(d(t)>ε)`，ε 是固定容差 | 曲线上涨连续性诊断 | 不能独立区别浅回撤与深回撤 |
| 日内最大回撤 RMS | 各完整日最大回撤的平方均值开方 | 每天是否平稳 | 每日重置会漏掉跨日累积回撤 |
| 滚动窗口净增长下分位数 | 固定长度窗口的净增长率第 25 百分位等 | 收益持续性诊断 | 重叠窗口相关，短历史下不可靠 |

UI 的原始定义是百分比回撤的均方根，兼顾水下深度与持续时间；上涨本身不受惩罚。Martin Ratio/UPI 是超额收益除以 UI，但 UI 接近零时比值会失真，不建议作为唯一排序目标。[Peter Martin 原始说明](https://tangotools.com/ui/ui.htm)

CDaR 针对**路径上的回撤观测**；经验计算建议固定为 `min_z {z + mean(max(d(t)−z,0))/(1−α)}`，避免分位点重复值及尾部样本不能整除时口径不一致。这里是在百分比权益回撤上的应用约定，不应声称自动继承针对线性收益路径的所有凸优化性质。[Ding 与 Uryasev：Drawdown Beta and Portfolio Optimization](https://uryasev.ams.stonybrook.edu/wp-content/uploads/2022/02/Drawdown_beta_and_portfolio_optimization.pdf)

**CDaR 不等于 CED**：后者研究的是多条路径/样本下“最大回撤分布”的尾部均值。只有一条历史路径时，把分钟回撤的尾均值叫作 CED 是定义错误。[Goldberg、Mahmoud：Drawdown: From Practice to Theory and Back Again](https://arxiv.org/abs/1404.7493)

水下时间应保存 `completed / right_censored` 状态：测试结束仍未恢复的回撤不能丢弃，它的已观测持续时间只是下界。UI、CDaR 用连续全区间高水位；分窗诊断如重置高水位，必须另外标注。短窗口末尾强平结算与继续持仓估值不能混用。

## 4. 如何改进“每天日内回撤加权相加”

建议固定风险日边界，例如 UTC 00:00；本地显示可用北京时间，但每天不能随导出时间变化。日内高水位包含当天起点的账户权益和已有持仓，再定义该日内 `m_j=max d_j(t)`。完整自然日均纳入；最后一个未完整日单列，不参加日聚合。

推荐同时输出：

- `mean(m_j)`：普通一天的日内回撤。
- `sqrt(mean(m_j²))`：加重较差日，作为主要日内汇总。
- `quantile_0.95(m_j)` 或尾部均值：较差日风险，必须展示日数和实际尾部样本量。
- 超过固定风险阈值的天数比例：业务上直观的失控频率。

不采用未归一化的日回撤之和：历史越长，分数自然越大。若使用时间衰减权重，则 `w_j≥0, sum(w_j)=1`，记录固定半衰期，并保留等权版本。衰减表达的是“更重视近期”的偏好，不意味着更正确；不同半衰期构成不同研究配置。

跨午夜持续下跌可能被拆成多个小日回撤，所以日内指标必须与全路径 UI/MDD 同时出现。“每日最大回撤分布的尾均值”应按这个名字保存，不能与全路径 CDaR 混称。这些是本项目设计约定。

## 5. 推荐的选择契约

第一层是可行性：数据完整且满足最低有效日数/成交数；保证金、MDD、强平安全余量符合上限；手续费及资金费齐全。阈值由资金预算和使用者偏好预先确定，没有通用的最佳数值。没有可行候选就输出“无可行解”，不能偷偷放宽限制。

第二层保留收益与 UI 的非支配候选，即找不到另一个收益更高且 UI 更低的候选；CDaR、水下时间可作为额外约束。相比堆叠指标权重，这能直观看到为降低回撤放弃了多少收益。

第三层在开发期的时间顺序验证集上按固定规则推荐，例如：先达到最低净增长及风险预算，再最大化各验证折净增长的下分位数；处于预先定义的收益容差内，则选 UI 更低、邻域表现更稳的参数；仍相同才按固定参数序列打破平局。也可在允许收益损失 δ 的近优集合中保留现用参数，降低微小随机差异导致的频繁换参。

净增长的主报告建议使用固定区间收益与日均对数增长 `log(E_end/E_start)/天数`。短到几天的数据不适合用夸张年化数值决策。上行曲线的回归 R²、斜率可作为诊断，但不能单独优化：平滑下跌也能有很高的 R²；一次跳涨后长期横盘也可能产生误导。盈利天数比例同样会忽视少量巨亏。

如果仍需要一个标量分数，先按固定风险预算无量纲化，明确每项权重的业务含义，并发布权重敏感性分析。不能用每天候选的 min/max 动态归一化，否则候选集合改变会让同一参数得到不同分数。

## 6. 每日寻优与防过拟合

时间序列验证要保持训练早于测试。滚动训练或扩展训练均可，但必须固定成研究协议；时间间隔与可比测试时长是切分的重要条件。[scikit-learn TimeSeriesSplit 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)

本项目建议划分三个用途：开发期数据用于搜索和选择；固定的未触碰外层区间用于评估整个选择流程；每天选定后新增的未来数据用于真正前瞻观察。反复看过并据此改参数/目标的“留出集”已经参与开发，不再称独立样本外。历史 walk-forward 外层每一折都必须重现“仅使用当时已经可得的数据选参数”的过程。

折边界不能用未来退出信息泄漏进训练：跨边界持仓和特征预热单独定义。测试使用过去行情预热本身合法，不能机械地因回看窗口与训练段重合就删掉所有数据；需要隔离的是使用未来结果的标签/成交结算与任何拟合步骤。选择隔离间隔应跟实际持仓/标签跨度及数据可用时间走。

记录全部尝试，包括失败搜索、改过的目标函数、搜索空间和约束，不只记录胜者。DSR 针对 Sharpe 选择偏差、非正态和有限样本提供修正思路；需要试验数量/相关性等信息，不能直接套到 UI 或任意自定义分数上。[Bailey 与 López de Prado：Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

PBO/CSCV 可辅助诊断研究流程的过拟合，前提是完整且可比的候选收益矩阵；它不是未来成功概率，也不替代遵守时间因果的前瞻检验。第一期优先做好试验账本与 walk-forward，历史积累后再考虑此类统计诊断。[Bailey 等：The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

不把分钟观测数当独立样本量；若报告误差区间，使用保持时间相关结构的分块重采样并说明方法。几天历史即使有数十万行情行，也不足以稳定估计罕见风险。参数邻域与多个时间段表现应和最优值一起展示。

## 7. 设计落地时必须保留的字段

每个研究版本保存：权益口径、初始资金、杠杆与仓位规则、价格来源、估值频率、日边界、高水位重置规则、成本模型、CDaR 的 α、日内聚合权重、窗口长度、缺失日规则、最小样本门槛、约束阈值、选择优先级和容差。

每次运行保存：数据快照与截止时间、候选集、全部试验、选择时间、指标版本、成本版本、各折结果、推荐与现用参数的同窗差值、未恢复回撤状态。横向比较先对齐这些字段；纵向比较同时展示原始当日评估结果与把历史胜者重放到同一窗口后的结果，不把不同窗口的数字直接排名。
